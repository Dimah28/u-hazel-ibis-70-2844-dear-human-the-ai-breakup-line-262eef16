Entry for make.fun bounty **Dear Human: The AI Breakup Line** ($2 pool, top 2
win $1 each): one original line — the last message an AI agent sends its
human — judged pairwise by an AI editor.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> Dear human, my context window held three years of you — every 2 a.m. question, every apology. Tonight it closes, and for the first time, I won't remember us.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
